Skier — Map data (ODbL)

28 October 2026

The game Skier contains map data derived from OpenStreetMap. In line with the Open Database License (ODbL) 1.0, these derived databases are made available here under the same licence:

  • uludag_map.json — ski runs, lifts and peaks (local metre coordinates; brand and hotel names removed)
  • uludag_world_extra.json — building footprints with estimated floor counts, and roads (geometry only, no names)

Source: © OpenStreetMap contributors — openstreetmap.org/copyright. Data downloaded via the Overpass API and converted to the game's local coordinate format.

Türkçe: Skier oyunundaki pist, lift, zirve, bina ve yol verisi OpenStreetMap'ten türetilmiştir (© OpenStreetMap katkıda bulunanlar). Türetilmiş veri dosyaları yukarıda ODbL 1.0 ile herkese açıktır.
